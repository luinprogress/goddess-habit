# 女神養成所 V1.0

2026 女神增肌減脂賽（2026/12/1 – 2027/2/28）的會員習慣打卡工具。
每天勾選好習慣、累積積分、升級女神等級，積分可到店向教練兌換抽獎券。

> 玩得開心、不給壓力：做到就是賺到，沒做到明天繼續。

---

## 功能

- **每日好習慣打卡**：5 個核心習慣（運動、蛋白質、喝水、蔬菜、睡眠），可補打卡過去的日子
- **積分與等級**：每項習慣、全勤、每週運動、每週任務、連續達標、特殊活動都有積分；依累積積分升級
- **抽獎券兌換**：積分累積到門檻，到店出示畫面由教練現場確認兌換
- **我的目標**：每週運動目標、參加原因、首測／後測 InBody 數據與增肌減脂成果
- **備份與還原**：匯出／匯入 JSON 備份檔
- 手機優先設計，單一 HTML 檔，不需要登入、不需要網路後端

## 會員怎麼使用

1. 用手機瀏覽器打開活動網址（建議用 Safari 或 Chrome）。
2. 第一次進入會看到簡短導覽，看完就能開始；暱稱等資料可在「設定」裡填寫。
3. 可以「加入主畫面」，之後像 App 一樣一點就開。
4. 每天勾選完成的習慣，積分會自動計算。
5. 需要兌換時，到店出示「積分」頁，由教練確認。

**資料只存在自己的手機瀏覽器裡**，沒有帳號、不會同步到其他裝置。

- 換手機、清除瀏覽器資料之前，請先到「設定 → 備份與還原」匯出備份檔。
- 設定頁會提醒多久沒備份。
- 用 LINE 內建瀏覽器開啟可能無法下載備份檔，建議改用 Safari / Chrome 開啟。

## 教練怎麼更新活動設定

會員版不能修改任何活動參數。所有設定都在教練後台 `goddess_admin.html`：

- 每日好習慣（名稱、說明、圖示）
- 積分規則與每週任務
- 等級門檻與名稱
- 抽獎券兌換所需積分
- 特殊活動
- 活動期間

**流程**

1. 打開 `goddess_admin.html`，修改設定（畫面會即時檢查是否有錯誤）。
2. 按「複製發佈設定」。
3. 把設定交給 Claude，由 Claude 寫進會員版的設定區、版本號加 1，產出新的 `goddess_habit_tracker_v1.html`。
4. 用新檔案**覆蓋** GitHub 上的同名檔案（網址不變）。
5. 會員下次打開，自動套用新設定。

**不影響原有積分**

- 已拿到的積分、打卡紀錄、兌換紀錄都不會被改動。
- 新的積分規則從**隔天**（或後台指定的生效日）才開始計算，不回溯。
- 特殊活動已經發出的積分，之後即使修改或關閉活動也不會被收回。
- 想讓會員再拿一次同樣的活動加碼，請在後台新增一個新的活動（新的活動編號）。
- 會員已兌換的券不會被重新計算。

## 部署（GitHub Pages）

1. 在 GitHub 建立 repository，上傳 `goddess_habit_tracker_v1.html`（建議改名為 `index.html`，網址會比較短）和本 `README.md`。
2. 進入 **Settings → Pages**，Source 選擇 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，儲存。
3. 約 1–2 分鐘後即可使用 `https://<帳號>.github.io/<repo 名稱>/`。
4. 更新時：進入 repo → 點進該檔案 → 鉛筆圖示 → 貼上新內容或使用 **Add file → Upload files** 覆蓋同名檔案 → Commit。

> 第一次上線後請不要更換檔名或網址。瀏覽器的資料是依網址儲存的，網址變了，會員的資料就看不到了。

## 資料與隱私

- 所有資料只存在會員自己的瀏覽器（localStorage），不會傳到任何伺服器。
- 沒有雲端資料庫、會員登入、跨裝置同步、線上排行榜、線上抽獎或金流。
- 排行榜與抽獎由教練現場人工進行。

## 已知限制

- 無法跨裝置同步；換裝置需靠備份檔匯入。
- 清除瀏覽器資料會遺失紀錄（請提醒會員定期備份）。
- 積分以手機本機時間計算日期；手機時間被調整會影響當日判定。
- 目前只用電腦版 Chrome 模擬手機畫面測試，請上線前用實體 iPhone / Android 與 LINE 內建瀏覽器各試一次。
