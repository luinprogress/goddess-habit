## 📱 開始使用

1. 用手機打開活動網址（Safari 或 Chrome 最順）
2. 點「分享」→「加入主畫面」，之後一點就開，像 App 一樣 📲
3. 每天勾選完成的習慣，積分自動幫你算好

## 💾 一定要記得備份！

你的紀錄**只存在自己的手機裡**，不會上傳到任何地方 🔒
所以請定期到 **設定 → 備份與還原** 匯出備份檔，換手機或清除資料時就不怕不見囉。

> 小提醒：用 LINE 裡面的瀏覽器開，可能下載不了備份檔，建議用 Safari 或 Chrome 開 🙌

## 💬 常見問題

**忘記打卡怎麼辦？**
可以在「今天」頁切換到前幾天補打卡。

**換手機了，紀錄怎麼辦？**
舊手機匯出備份檔，新手機到「設定 → 備份與還原」匯入就好。

**活動規則有更新，我的積分會不見嗎？**
不會！已經拿到的積分都會保留 💖
